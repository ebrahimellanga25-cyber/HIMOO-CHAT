# HIMOO CHAT

Welcome to HIMOO CHAT.

HIMOO CHAT is a social communication application.

## Main Features

- User Registration and Login
- Voice Chat Rooms
- Private Messages
- Coins and Diamonds Wallet
- Gifts and Exclusive Frames
- VIP Levels
- Agencies and Agents
- User Targets
- Withdrawal System
- Games and Lucky Wheel
- CEO and Admin Control Panel

## Administration

The General Manager (CEO) has the highest authority in the application.

The system supports managers, super admins, admins, and assistants with assigned permissions.

## Project Goal

Build a complete social chat application with advanced features and full administrative control.
